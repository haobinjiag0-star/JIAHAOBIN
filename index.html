可用 · 本地导入

导入不同网站的 CSV

上传后会自动识别常见中、日、英文字段，并显示字段映射和数据预览。你可手动调整映射；支持 UTF-8 与常见日文 Shift-JIS 导出。导入会追加并去重，不会覆盖之前导入的清单。

可识别：企业名、行业、职位、应聘对象、企业规模、勤務地、截止日、募集状态、応募URL、募集说明
CSV 表头因网站不同而异时，可在预览窗口手动指定对应列。
演示 · 非实时

内置样例数据

样例企业和募集状态为虚构数据，只用于体验筛选与收藏。它们不会导向真实申请页面，也不能作为真实求职信息使用。

推荐字段：company / industry / candidate / size / location / openUntil / url / description
日期格式：YYYY-MM-DD；多个招聘对象用分号分隔。
GitHub · 公开信息

GitHub 作品经历

ES 工作室可读取公开账号及最近更新的公开仓库，用仓库语言、描述和 Star 数补充项目经历。私有仓库不读取。

只需 GitHub 用户名。数据由浏览器请求 api.github.com，GitHub 的公开 API 限额和可用性适用。
隐私 · 本地浏览器

材料与草稿的处理方式

此原型只在浏览器本地读取你选择的文本文件，资料字段、收藏、导入的清单和草稿写入本机 localStorage。换设备或清除浏览器数据后不会自动同步。

此处的“生成”是本地模板组装，不是云端大语言模型。之后可接入你选择的 AI 服务或自建后端。
